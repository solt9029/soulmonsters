# チェーン処理システムの実装

遊戯王のようなチェーンシステムを実装する。将来的にブロックカードといったカテゴリのカードで、ターンプレイヤー以外（相手プレイヤー）が、ターンプレイヤーの効果の発動に対して何かアクションが取れる状態を作りたいと思っている。


## 実装の進め方

### STEP1: GameChain概念の導入（だけ）

最初からいきなり全てを作ろうとは思っていない。まずは既存実装に対して「GameChain」と概念を追加する。ここで、「効果発動した後に相手に優先権の確認をする」などは一切行わない。既存のAction Handlerが行っていたことの中に、単にGameChainの概念を混ぜ込むだけである

#### 例: プレイヤーAが「懐かしのルード」の効果を発動し、dispatchActionが呼ばれる場合

- 1: Action Handler → コストのエナジー2を減らす。GameChain(RESOLVING) + GameChainLink(RESOLVING)を生成する
- （ここで理想的には相手プレイヤーへ優先権の確認を行うが、最初は実装しない）
- 2: GameChainがあるのでChain Resolver → 最後のRESOLVINGのGameChainの最後のRESOVLINGのGameChainLinkの処理を実行する（対象モンスターを700下げる）。そして、GameChainLinkをRESOLVEDに変更する。さらに、GameChainをRESOLVEDに変更する

#### 例: プレイヤーAがプレイヤーBの「進化したバクボムダン」を攻撃して倒す場合

- 1: Action Handler → 「進化したバクボムダン」をソウルゾーンへ置き、差分だけダメージをプレイヤーBに与える。攻撃したことを記録するためにGameStateを作成する。「進化したバクボムダン」がソウルゾーンに置かれたので、GamePendingEffectを作成する
- 2: GamePendingEffectがあるのでChain Builder → GameChain(RESOLVING) + GameChainLink(RESOLVING)を生成し、GamePendingEffectを削除する
- 3: GameChainがあるのでChain Resolver → 最後のRESOLVINGのGameChainの最後のRESOVLINGのGameChainLinkの処理を実行する（プレイヤーAが600ダメージを受ける）。そして、GameChainLinkをRESOLVEDに変更する。さらに、GameChainをRESOLVEDに変更する

### STEP2: 「ハモンタキーに狩られぬもの」の効果実装

STEP1が終わったら、次はGamePendingEffectからGameChain + GameChainLinkが生まれることが通常想定される「ハモンタキーに狩られぬもの」の効果を実装する。

「ハモンタキーに狩られぬもの」については、自ら能動的に発動するわけではなく、「ソウルゾーンに置かれた時」に受動的に発動するものの、効果処理にあたって事前に「モルグゾーンのカードを選ぶ」必要がある。つまり、GameChainLinkがRESOLVINGで実際に効果処理を進める際に一度ストップし、ユーザーに対して「どのカードを選ぶか」の選択をさせて、再度GraphQLのmutationを叩いてもらう必要がある

#### 例: プレイヤーAがプレイヤーBの「ハモンタキーに狩られぬもの」を攻撃して倒す場合

- 1: Action Handler → 「ハモンタキーに狩られぬもの」をソウルゾーンへ置き、差分だけダメージをプレイヤーBに与える。攻撃したことを記録するためにGameStateを作成する。「ハモンタキーに狩られぬもの」がソウルゾーンに置かれたので、GamePendingEffectを作成する
- 2: GamePendingEffectがあるのでChain Builder → GameChain(RESOLVING) + GameChainLink(RESOLVING)を生成し、GamePendingEffectを削除する
- 3: GameChainがあるのでChain Resolver → 後のRESOLVINGのGameChainの最後のRESOVLINGのGameChainLinkの処理を実行しようと試みる。「モルグゾーンのカードを選ぶ」必要があるため、ここで一度ストップする
  - GameChain:
    - status: RESOLVING
  - GameChainLink（ハモンタキーに狩られぬもの）:
    - payload: null
    - status: RESOLVING
- 4: Gameオブジェクトを返却する際にGrantor → モルグゾーンのカードの□族モンスターに「SELECT_AS_HAMONTAKI_TARGET」のようなActionTypeを付与する
- 5: プレイヤーBはモルグゾーンのカードの□族モンスターを1枚選び、「SELECT_AS_HAMONTAKI_TARGET」でdispatchActionする
- 6: GameChainがあるのでChain Resolver → モルグゾーンのカードの□族モンスターがpayloadとして渡ってきて、これをもとに「ハモンタキーに狩られぬもの」の効果を処理する。そして、GameChainLinkをRESOLVEDに変更する。さらに、GameChainをRESOLVEDに変更する

### STEP3: 全て実装する

まだ詳細には考えられてませんが、最終的には優先権の確認（GameChainLinkConfirmation）などの実装を加えます。


## テーブル設計
### GameChain
チェーンを表す概念。

- id
- gameId
- status: BUILDING, RESOLVING, RESOLVED

### GameChainLink
チェーンブロックを表す概念。

- chainId
- orderIndex: number
- userId: string
- gameCardId: number | null
- effectType: EffectType
- status: WAITING, RESOLVING, RESOLVED
- payload: JSON

### GameChainLinkConfirmation
チェーンブロックに対して優先権の確認を表す概念。

- chainLinkId
- userId

### GamePendingEffect
チェーン組み立て中のコストや、チェーン処理中に効果が発動した時に、該当チェーン終了後に、チェーン組み立てを開始するために待機するための概念。例: 遊戯王であれば、ライコウでウォルフが墓地に送られた場合に、ウォルフの効果がライコウの効果のチェーン処理解決を待つ必要があるなど。

GamePendingEffectではまだ順番も決まっておらず発動するかどうかも決まってない都合上、コスト処理前のものが入る。

- userId
- gameCardId
- effectType: EffectType

## アプリケーションコード上の概念

### EffectType
上記のテーブル設計でもEffectTypeという型を記載しているが、これはActionTypeに似たものである。大きな違いは以下の通り

- ActionType: ユーザーが何かしらの行動を起こすことを表す
  - モンスターの召喚（エナジーの消費を含む）
  - モンスターの攻撃（ダメージ計算などを含む）
  - プットタイムの開始
  - 「懐かしのルード」の効果発動（コスト処理を含む）
- EffectType: 効果の処理自体を表す
  - 「進化したバクボムダン」のダメージ効果
  - 「懐かしのルード」の効果（攻撃力を下げる）

### ActionHandler
すでにある概念。ただし、ChainResolverに効果処理を移動するため、ActionHandlerの役割が変わる。「攻撃、召喚などのチェーンブロックを作らない処理」「発動コストの処理」などはこの中で引き続き実行する

#### 現在の場所と構造
- ファイル: `server/src/game/actions/handlers/index.ts`
- クラス: `GameActionHandler`
- メソッド: `handleAction(data: GameActionDispatchInput, userId: string, gameModel: GameModel): GameModel`

#### 処理フロー（既存）
1. `validateAction`でバリデーション実行
2. `ActionType`によって対応するハンドラー関数を呼び出す
3. `gameModel`を更新して返却

### ChainBuilder
新規概念。GamePendingEffectからGameChain + GameChainLinkを生成する。

#### 配置場所
- ファイル: `server/src/game/chain/builder.ts` (新規作成)
- クラス: `ChainBuilder`

#### メソッド構成
```typescript
@Injectable()
export class ChainBuilder {
  constructor(
    private readonly gameChainRepository: GameChainRepository,
    private readonly gameChainLinkRepository: GameChainLinkRepository,
    private readonly gamePendingEffectRepository: GamePendingEffectRepository,
  ) {}

  /**
   * GamePendingEffectが存在すればGameChain + GameChainLinkを生成する
   * STEP1では1つのGamePendingEffectのみ処理（将来的には複数対応）
   */
  async buildChainIfNeeded(gameModel: GameModel): Promise<GameModel> {
    // GamePendingEffectが存在しない場合は何もしない
    if (gameModel.gamePendingEffects.length === 0) {
      return gameModel;
    }

    // STEP1: 最初のGamePendingEffectのみ処理
    const gamePendingEffect = gameModel.gamePendingEffects[0];

    // GameChain (RESOLVING) を生成
    const gameChain = new GameChainModel({
      gameId: gameModel.id,
      status: 'RESOLVING',
      createdAt: new Date(),
      updatedAt: new Date(),
    });
    gameModel.gameChains = [...gameModel.gameChains, gameChain];

    // GameChainLink (RESOLVING) を生成
    const gameChainLink = new GameChainLinkModel({
      chainId: gameChain.id,
      orderIndex: 0,
      userId: gamePendingEffect.userId,
      gameCardId: gamePendingEffect.gameCardId,
      effectType: gamePendingEffect.effectType,
      status: 'RESOLVING',
      payload: gamePendingEffect.payload,
      createdAt: new Date(),
      updatedAt: new Date(),
    });
    gameModel.gameChainLinks = [...gameModel.gameChainLinks, gameChainLink];

    // GamePendingEffectを削除
    gameModel.gamePendingEffects = gameModel.gamePendingEffects.filter(
      (gpe) => gpe.id !== gamePendingEffect.id
    );

    return gameModel;
  }
}
```

#### STEP3での拡張予定
- 複数GamePendingEffectの優先順位制御
- GameChainLinkConfirmationの生成（優先権確認）
- GameChain status: BUILDINGの導入

memo: STEP1では同時に複数の効果が発動（誘発）した場合（つまりGamePendingEffectが同時に複数ある場合）は考慮しない。

### ChainResolver
新規概念。GameChainLinkをorderIndexの大きい順に処理していく。効果処理時にユーザーの行動が必要であれば（例: 「ハモンタキーに狩られぬもの」のような効果）、いったんそこで停止する

#### 配置場所
- ファイル: `server/src/game/chain/resolver.ts` (新規作成)
- クラス: `ChainResolver`

#### メソッド構成
```typescript
@Injectable()
export class ChainResolver {
  constructor(
    private readonly gameChainRepository: GameChainRepository,
    private readonly gameChainLinkRepository: GameChainLinkRepository,
  ) {}

  /**
   * RESOLVING状態のGameChainが存在すれば処理する
   */
  async resolveChainIfNeeded(gameModel: GameModel): Promise<GameModel> {
    // RESOLVING状態のGameChainを取得（最後のもの）
    const resolvingGameChain = gameModel.gameChains
      .filter((c) => c.status === 'RESOLVING')
      .sort((a, b) => b.createdAt.getTime() - a.createdAt.getTime())[0];

    if (!resolvingGameChain) {
      return gameModel;
    }

    // RESOLVING状態のGameChainLinkを取得（orderIndexが最大のもの）
    const resolvingGameChainLink = gameModel.gameChainLinks
      .filter((cl) => cl.chainId === resolvingGameChain.id && cl.status === 'RESOLVING')
      .sort((a, b) => b.orderIndex - a.orderIndex)[0];

    if (!resolvingGameChainLink) {
      // GameChainLink全て解決済み → GameChainを解決済みに
      resolvingGameChain.status = 'RESOLVED';
      resolvingGameChain.updatedAt = new Date();
      return gameModel;
    }

    // GameChainLinkの効果を解決
    gameModel = await this.resolveGameChainLink(gameModel, resolvingGameChainLink);

    return gameModel;
  }

  /**
   * 個別のGameChainLinkを解決する
   */
  private async resolveGameChainLink(
    gameModel: GameModel,
    gameChainLink: GameChainLinkModel
  ): Promise<GameModel> {
    // effectTypeに応じて効果を実行
    switch (gameChainLink.effectType) {
      case EffectType.EFFECT_NATSUKASHINORUDE_POWER_DOWN: {
        // payloadにtargetGameCardが入っている前提
        if (!gameChainLink.payload || !gameChainLink.payload.targetGameCard) {
          // STEP2: payloadが不完全な場合は処理を停止
          // この場合、Grantorで「SELECT_TARGET」を付与して待機
          return gameModel;
        }

        // 効果処理を実行（元々handleEffectNatsukashinorudePowerDownにあった処理）
        const newGameState = new GameStateModel({
          gameCardId: gameChainLink.gameCardId,
          state: {
            type: StateType.EFFECT_NATSUKASHINORUDE_POWER_DOWN,
            data: {
              targetGameCardId: gameChainLink.payload.targetGameCard.id,
              value: 700,
            },
          },
          createdAt: new Date(),
          updatedAt: new Date(),
        });
        gameModel.gameStates = [...gameModel.gameStates, newGameState];

        // GameChainLinkを解決済みに
        gameChainLink.status = 'RESOLVED';
        gameChainLink.updatedAt = new Date();

        return gameModel;
      }

      case EffectType.SHINKASHITABAKUBOMDAN_DAMAGE: {
        // 効果処理: プレイヤーAに600ダメージ
        const attackerUserId = gameChainLink.payload?.attackerUserId;
        const gameUser = gameModel.gameUsers.find((gu) => gu.userId === attackerUserId);
        if (gameUser) {
          gameUser.lifePoint -= 600;
        }

        // GameChainLinkを解決済みに
        gameChainLink.status = 'RESOLVED';
        gameChainLink.updatedAt = new Date();

        return gameModel;
      }

      case EffectType.HAMONTAKI_SPECIAL_SUMMON: {
        // STEP2: payloadにtargetGameCardが必要
        if (!gameChainLink.payload || !gameChainLink.payload.targetGameCard) {
          // 処理を停止し、Grantorで選択肢を付与
          return gameModel;
        }

        // 効果処理: モルグゾーンのカードを特殊召喚
        const targetCard = gameChainLink.payload.targetGameCard;
        targetCard.zone = 'BATTLE';
        targetCard.position = /* 適切な位置を計算 */;
        targetCard.battlePosition = 'ATTACK';

        // GameChainLinkを解決済みに
        gameChainLink.status = 'RESOLVED';
        gameChainLink.updatedAt = new Date();

        return gameModel;
      }

      default:
        // 未対応のEffectTypeの場合はエラー
        throw new Error(`Unsupported effectType: ${gameChainLink.effectType}`);
    }
  }
}
```

#### 効果処理の移行方針
既存の`handleEffectXXX`関数にある効果処理ロジックを、`ChainResolver.resolveGameChainLink`に移動する。
- コスト処理: ActionHandlerに残す
- 効果処理: ChainResolverに移動

#### STEP2での拡張
- payloadが不完全な場合の停止処理
- 停止時のGrantorによる選択肢付与

#### STEP3での拡張
- GameChainLinkConfirmationの確認処理
- orderIndexの逆順処理（遊戯王のようなチェーン解決順）

#### dispatchGameActionメソッドの変更
```typescript
@Mutation(() => Game)
async dispatchGameAction(
  @Args('id', { type: () => Int }) id: number,
  @Args('data') data: GameActionDispatchInput,
  @User() user: UserInfo,
): Promise<Game> {
  const gameEntity = await this.gameService.findOneByIdOrFail(id);
  let gameModel = this.gameToModelMapper.toModel(gameEntity);

  // 1. ActionHandlerでアクションを処理
  gameModel = this.gameActionHandler.handleAction(data, user.userId, gameModel);

  // 2. ChainBuilderでGamePendingEffectからGameChainを構築
  gameModel = await this.chainBuilder.buildChainIfNeeded(gameModel);

  // 3. ChainResolverでGameChainを解決
  gameModel = await this.chainResolver.resolveChainIfNeeded(gameModel);

  // 4. GameModelをEntityに変換して保存
  const updatedGameEntity = await this.gameRepository.save(gameModel.toEntity());

  return this.gamePresenter.present(updatedGameEntity, user.userId);
}
```
