# やりたいこと
- 後から盤面を見た時にゲームの経緯が分かるようにしたい。

# 解決方法
- ゲームの処理を行うたびに、テキスト形式でその内容を記録する。

# 本当はやりたかったこと（スコープ外, 将来的にやるかも）
- テキストだけでなく、具体的に処理した内容を構造的に記録して、そのデータを読み込むとゲームの状態を再現できるようにしたかった。結構設計が大変そうなので、いったんやらない。

# gameLogs

- id
- gameId
- message

# 記録するタイミング

- actionをhandleしたタイミング
  - 例1: [プレイヤーの名前]がドロータイムを開始し、ドローしました。
  - 例2: [プレイヤーの名前]が[カードの名前]で直接攻撃しました。700のダメージを与えました。
  - 例3: [プレイヤーAの名前]が[カードの名前A]で[カードの名前B]を攻撃しました。[カードの名前B]を倒し、500のダメージを与えました。[プレイヤーBの名前]のエナジーが1増えました。
  - 例4: [プレイヤーの名前]が、ソウル3をコストとして[カードの名前]の効果を発動しました。
- pendingEffectを積むタイミング（主にevent handleしたタイミング）
  - 例1: 直接攻撃したとき、[カードの名前]の効果が発動しました。
- chainLinkをresolveしたタイミング
  - 例1: [カードの名前]の効果を処理し、デッキからカードを2枚ドローしました。
